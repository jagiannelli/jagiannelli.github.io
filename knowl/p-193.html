Given a smooth function \(f\text{,}\) we can always write down a Taylor series; there is no guarantee that the series converges to anything, let alone to the function. Given a smooth function \(f : \mathbb{R} \to \mathbb{R}\text{,}\) its Taylor series (around \(0\)) is

\begin{equation*} \sum_{n=0}^\infty \frac{f^{(n)}(0) \, x^n}{n!} \end{equation*}

A common mistake is to use \(f^{(n)}(x)\) instead of \(f^{(n)}(0)\text{.}\) Given a smooth function \(f : \mathbb{R} \to \mathbb{R}\text{,}\) its Taylor series expanded around \(a\) is

\begin{equation*} \sum_{n=0}^\infty \frac{f^{(n)}(a) \, (x-a)^n}{n!} \end{equation*} in-context
