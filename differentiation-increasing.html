    Section 8.4 Increasing and Decreasing Functions

    A function is increasing where its graph climbs as \(x\) grows, and decreasing where it falls. The gradient tells you which:
    🔗
    • \(f\) is increasing where \(f'(x) \gt 0\text{;}\)
      🔗
      🔗
    • \(f\) is decreasing where \(f'(x) \lt 0\text{.}\)
      🔗
      🔗
    🔗
    For a cubic, \(f'(x)\) is a quadratic, so there are two jobs. Either show that \(f\) is increasing for every \(x\), by showing the quadratic \(f'(x)\) is always positive; or find the range of \(x\) where \(f\) is increasing (or decreasing), by solving an inequality. The cells share their variables, so run them in order from the top.
    🔗

    Subsection 8.4.1 Increasing for every x

    Take \(f(x) = x^3 + 6x^2 + 16x - 5\text{.}\) First the setup, then step 1, diff:
    🔗
    Step 2, the completed square. Sage has no one-call completed square, so build it. For \(ax^2 + bx + c\text{,}\) \(p = -\frac{b}{2a}\text{,}\) and \(q\) is the value of the quadratic at \(p\) (its least value when \(a \gt 0\)). coefficient(x, 2) reads off \(a\) and coefficient(x, 1) reads off \(b\text{.}\) Then check it: expand multiplies \(a(x - p)^2 + q\) out, and bool(... == ...) says True when it is \(f'(x)\) again.
    🔗
    \((x + 2)^2\) is never negative, so \(f'(x) = 3(x + 2)^2 + 4 \ge 4\text{,}\) which is positive for every \(x\text{.}\)
    🔗
    Step 2, the other way: the discriminant. If \(b^2 - 4ac \lt 0\text{,}\) \(f'(x) = 0\) has no real roots, so \(f'(x)\) never crosses zero and has the same sign for every \(x\text{.}\) One value then gives that sign; \(x = 0\) is the easiest. (The discriminant alone does not say which side of zero \(f'\) is on.)
    🔗
    What solve says. solve(f'(x) > 0, x) answers [x < +Infinity], Sage’s way of saying “every \(x\)”, and solve(f'(x) < 0, x) answers [], “no \(x\)”. Good for checking, but it is not a proof: on paper you need one of the two routes above. (print shows Sage’s answer as plain text.)
    🔗
    The same, one step per line, the way it is written on paper:

    Subsection 8.4.2 Where increasing, where decreasing

    Now \(f(x) = x^3 - 3x^2 - 24x + 10\text{.}\) Differentiate, then factor shows the working you would write:
    🔗
    solve(f'(x) == 0, x) gives the critical values (.rhs() keeps the number, sorted puts them in order); solve on an inequality gives the range. Read its answer this way: conditions inside one inner list hold together (“and”); separate inner lists are alternatives (“or”).
    🔗
    The form of the answer matters. \(f'\) has a positive \(x^2\) term, an upward parabola, so it is positive outside the critical values: \(x \lt -2\) or \(x \gt 4\) (never “and”, since no \(x\) is both). It is negative between them: \(-2 \lt x \lt 4\text{,}\) which is “and”. In set notation RealSet writes the intervals, \((-\infty, -2) \cup (4, \infty)\text{;}\) the same set is \(\{x : x \lt -2\} \cup \{x : x \gt 4\}\text{.}\) union is \(\cup\) (“or”) and intersection is \(\cap\) (“and”).
    🔗
    Written up:
    🔗
    Habits that keep this right: write \(f'(x) \gt 0\) (or \(\lt 0\)) down before solving; use strict inequalities, which leave the critical values out; join the two outer parts with “or”; and check the direction by asking whether the parabola \(f'\) opens up or down.
    🔗
    🔗

    Subsection 8.4.3 f and f′ side by side

    On the left, \(f\) is green where it is increasing and red where it is decreasing; on the right, \(f'\) is shaded green where it is positive and red where it is negative. Example 1’s \(f'\) never reaches zero: its lowest point, the black dot, is the completed square’s \((p, q) = (-2, 4)\text{.}\) Example 2’s \(f'\) crosses zero at the critical values (dashed lines).
    🔗
    🔗

    Subsection 8.4.4 Checking a range with RealSet

    solve answers with lists, not a set. as_set below turns that answer into a RealSet, so you can compare it with your own. One trap: RealSet given two conditions joins them with “or”, so RealSet(x > -2, x < 4) is every \(x\text{,}\) not \(-2 \lt x \lt 4\text{.}\) For “and” use .intersection, as above.
    🔗
    Open and closed ends. < and > leave the end out, a round bracket; <= and >= keep it in, a square bracket. S[0] is the first piece of a set S, and .lower(), .upper(), .lower_closed() and .upper_closed() read its ends. in asks whether a number is in the set: a quick check of an answer. This section asks for strict inequalities, so its answers have open ends.
    🔗
    🔗

    Subsection 8.4.6 Practice with random questions

    Each seed gives a new cubic (the same seed always gives the same question), of one of the two kinds above: about one time in three “show that \(f\) is increasing”, otherwise the range where \(f\) is increasing or decreasing, with whole-number critical values or ones from the formula. Work it on paper first, then type your answer: for a “show that”, the completed square \(f'(x) = a(x - p)^2 + q\) as the list [a, p, q] (for \(2(x + 4)^2 + 7\) type [2, -4, 7]; the sentence that finishes the proof goes on paper); for a range, a RealSet, exact, or with surd ends to 2 decimal places.
